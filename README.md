# AAU MSc Software | Software 7 Group 5 | Adversarial input detection as a shared internet service

## About
Large language models (LLMs) can be tricked by adversarial user input: 
jailbreaks that bypass safety rules and prompt injections that override 
an app's instructions. This project studies how to detect such input 
before it reaches the model.

## Focus
- **Linguistic:** a typology of the evasion and persuasion strategies 
  attackers use.
- **Security:** a detector for jailbreaks and prompt injection, evaluated 
  adversarially by paraphrasing attacks to try to evade it.
